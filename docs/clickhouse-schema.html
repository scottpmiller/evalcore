internal.evaluations plain view one row per run

The whole scorecard on one row. Aggregates the score rows at read time in two steps: per metric, then per run. FINAL on the source so a redelivered insert collapses before it is counted.

schema definition 
CREATE VIEW IF NOT EXISTS internal.evaluations AS
SELECT
  timestamp, application, suite, variant, run_id,
  any(correlation_id)  AS correlation_id,
  any(dataset_version) AS dataset_version,
  any(judge_version)   AS judge_version,
  any(revision)        AS revision,
  any(suite_hash)      AS suite_hash,
  any(dataset_hash)    AS dataset_hash,
  any(adapter_mode)    AS adapter_mode,
  any(n_cases)         AS n_cases,
  any(n_samples)       AS n_samples,
  any(variant_knobs)   AS variant_knobs,

  groupArray(metric)        AS `metrics.metric`,
  groupArray(value)         AS `metrics.value`,
  groupArray(stddev)        AS `metrics.stddev`,
  groupArray(kind)          AS `metrics.kind`,
  groupArray(result_count)  AS `metrics.result_count`,
  groupArray(win)           AS `metrics.win`,
  groupArray(guardrail)     AS `metrics.guardrail`,
  groupArray(guardrail_gap) AS `metrics.guardrail_gap`,

  any(gate_verdict)     AS gate_verdict,
  any(gate_win)         AS gate_win,
  any(baseline_run_id)  AS baseline_run_id,
  any(baseline_variant) AS baseline_variant,
  any(win_baseline)     AS win_baseline,
  any(win_candidate)    AS win_candidate,
  any(win_delta)        AS win_delta,
  any(gate_summary)     AS gate_summary,
  countIf(guardrail = 'fail') = 0 AS guardrails_ok
FROM
(
  SELECT
    timestamp, application, suite, variant, run_id, metric,
    -- The engine calls a score per_case and the aggregate of them mean.
    CAST(multiIf(metric_kind = 'per_case', 'mean',
                 metric_kind = 'aggregate', 'aggregate',
                 'none')
         AS Enum8('none' = 0, 'mean' = 1, 'aggregate' = 2)) AS kind,
    -- An aggregate metric is one row, so the average is that row's value.
    avg(value) AS value,
    -- Sample stddev, matching the engine's statistics.stdev, and null below
    -- two observations for the same reason the engine returns None there.
    if(metric_kind = 'per_case' AND count(value) > 1,
       stddevSamp(value), NULL) AS stddev,
    if(metric_kind = 'aggregate',
       toUInt32(any(n_cases) * any(n_samples)),
       toUInt32(count(value))) AS result_count,
    max(win)           AS win,
    max(guardrail)     AS guardrail,
    max(guardrail_gap) AS guardrail_gap,

    any(correlation_id) AS correlation_id,
    any(dataset_version) AS dataset_version,
    any(judge_version) AS judge_version,
    any(revision) AS revision,
    any(suite_hash) AS suite_hash,
    any(dataset_hash) AS dataset_hash,
    any(adapter_mode) AS adapter_mode,
    any(n_cases) AS n_cases,
    any(n_samples) AS n_samples,
    any(variant_knobs) AS variant_knobs,
    any(gate_verdict) AS gate_verdict,
    any(gate_win) AS gate_win,
    any(baseline_run_id) AS baseline_run_id,
    any(baseline_variant) AS baseline_variant,
    any(win_baseline) AS win_baseline,
    any(win_candidate) AS win_candidate,
    any(win_delta) AS win_delta,
    any(gate_summary) AS gate_summary
  FROM internal.evaluation_scores FINAL
  -- A failed invocation carries no metric and is not a scorecard entry.
  WHERE metric != ''
  GROUP BY timestamp, application, suite, variant, run_id, metric, metric_kind
)
GROUP BY timestamp, application, suite, variant, run_id;

internal.evaluation_invocations plain view one row per case x sample

Duration, tokens, cost and the error fields sit at this grain but are stored one level finer, so they repeat across a case's metric rows. Reading them here is what makes sum(cost) correct.

schema definition 
CREATE VIEW IF NOT EXISTS internal.evaluation_invocations AS
SELECT
  timestamp, application, suite, variant, run_id, case_id, sample_idx,
  any(duration)      AS duration,
  any(input_tokens)  AS input_tokens,
  any(output_tokens) AS output_tokens,
  any(cost)          AS cost,
